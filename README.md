# LytRacer
A Spigot plugin that supports Minecraft 26.3 for Elytra time trials. Currently under development with no features complete.

## Build
Requires JDK 25.

To build this project, clone it into a directory and type `./gradlew build`. This also runs the tests.

## Install
To install this project, take `build/libs/LytRacer-<version>.jar` and put it into your Spigot/Paper server's plugins directory.
